## Результат

Сервер хранит каталог из 24 метрик в 4 группах с каноническими единицами. Обратимая миграция Alembic добавляет исходные данные, а динамический тест проверяет API по каталогу.

Frontend на `/m/health` показывает группы, состояние «Нет данных» и ссылку на Apple Settings. iOS читает все 24 типа только для чтения через HealthKit, запрашивает разрешение при первом входе на вкладку Health и явно показывает пустое состояние и переход в Settings.

```mermaid
  C[Каталог: 24 метрики, 4 группы] --> A[Dynamic API]
  A --> W[Frontend Health]
  C --> H[iOS HealthKit]
  W --> E[Нет данных / Settings]
  H --> E
```
